# Features implemented

* __Dynamic Table & Filtering:__ Located in the "Development Log" sidebar on the right; use the dropdown or checkbox to filter projects instantly, type in the title field and click "Add Project" to add a new entry, or click the "❌" button on user-added rows to delete them.

* __Custom Form Validation:__ Located in the "Contact" section at the bottom of the page; leave fields empty or enter an invalid email and click "Send" to see the custom inline error messages.

* __Dark Mode:__ Located at the top-right corner of the header; click the "Dark mode" button to toggle the theme across the entire page.
